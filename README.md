# E-Commerce Review Analyzer MAS

Multi-agent system (CTSE Assignment 2): scrape/load reviews → analyze → fraud signals → buyer recommendation. Runs **locally** with **Ollama** (no paid LLM APIs).

## Prerequisites

- Python **3.9+** (this repo pins LangGraph 0.2.x for broad compatibility; **3.10+** recommended if you upgrade to LangGraph 0.6+ later)
- [Ollama](https://ollama.com) installed; pull a model, e.g. `ollama pull llama3.1:8b`

## Setup

```powershell
cd ecommerce-review-analyzer-mas
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Dataset from Hugging Face (do this first)

The MAS reads **local CSV** only at runtime (fits the assignment: tools + local files). Hugging Face is used **once** to build that file.

1. **Export** a slice of **Electronics** reviews (real `product_id`, rating, timestamp) using `McAuley-Lab/Amazon-Reviews-2023`:

   ```powershell
   python scripts/export_hf_reviews.py --limit 3000 --output data/hf_reviews_electronics.csv
   ```

   - This uses **streaming** so it exports only the first N rows without downloading the entire dataset (the full Electronics split is huge).
   - You can change `--limit` to export more/less.

2. **Run the pipeline** on that file:

   ```powershell
   python run.py --dataset data/hf_reviews_electronics.csv
   ```

**Report / demo:** Cite the dataset name and Hugging Face link; state that inference runs **locally** and the CSV is a **local snapshot**.

| `src/review_mas/nodes.py` | Agent step functions (stubs → real) |
| `src/review_mas/tools/` | Custom Python tools (one+ per teammate) |
| `data/sample_reviews.csv` | Tiny built-in sample |
| `data/hf_reviews_electronics.csv` | Generated by `scripts/export_hf_reviews.py` (not committed if large) |
| `scripts/export_hf_reviews.py` | One-shot Hugging Face → CSV export |
